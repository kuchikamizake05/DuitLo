# Approved design references

The approved light and dark HTML design snapshots were authored in October 2026. They are historical design inputs, not runtime assets.

Use `python tools/design/import-reference.py --source-dir <approved-html-directory>` to provide their location explicitly. Import metadata is stored in `tools/design/reference/`. Generated components are in `src/components/reference/`; current financial adapters and manual bindings must be preserved when reviewing generated output.
